## 🚀 How to Install
   
### **Method 1: Install for Current User (Recommended)**
1. Navigate to the `release` folder in your project directory
2. Double-click `Document Storage App Setup 1.0.0.exe`
3. Follow the installation wizard:
   - Choose installation directory (default is recommended)
   - Select "Create desktop shortcut" ✅
   - Select "Create Start Menu shortcut" ✅
   - Click "Install"
4. Wait for installation to complete
5. Click "Finish" and optionally launch the app

### **Method 2: Portable Version**
If you prefer not to install, you can run the app directly:
1. Go to `release/win-unpacked/`
2. Double-click `Document Storage App.exe`
3. The app will run without installation

## 🛠️ Troubleshooting

### **Installation Issues**
- **"Windows protected your PC"**: Click "More info" → "Run anyway"
- **Permission denied**: Right-click installer → "Run as administrator"
- **Antivirus blocking**: Add exception for the installer

### **Runtime Issues**
- **App won't start**: Check Windows Event Viewer for errors
- **Database errors**: Delete `documents.db` to reset (loses data)
- **Search not working**: Restart the app

### **Uninstalling**
- **Windows 10/11**: Settings → Apps → Document Storage App → Uninstall
- **Control Panel**: Programs → Uninstall a program → Document Storage App
